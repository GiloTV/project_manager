# Project Manager ✏️
​​​

A command-line application built with Python and SQLite to organize projects and their tasks.

## About 💡

This project is part of my learning journey from Jr. Test Engineer toward backend development. It builds on my previous Expense Tracker by introducing relationships between database tables, SQL joins, task filtering, and a modular Python structure.

Users can create projects, add tasks to each project, update task details, mark tasks as completed or pending, and delete tasks. Each task includes a description, creation date, due date, status, and priority. Data is stored persistently in SQLite.

## Features 🛠️​

- Create and display projects.
- Add tasks to an existing project.
- Display tasks for one project or across all projects.
- Update task names, descriptions, due dates, statuses, and priorities.
- Delete tasks.
- Filter tasks by priority or completion status.
- Find overdue pending tasks and pending tasks due today or later.
- Validate user input and check that selected tasks belong to the selected project.

## What I Practiced ✒️

- Designing related tables with primary and foreign keys.
- Using SQL joins to retrieve project and task information.
- Writing parameterized queries for inserts, updates, deletions, and filters.
- Organizing Python code into separate modules.
- Creating reusable input-validation functions.
- Debugging function arguments, menu flows, and database operations.
